# 🧮 NovaCalc

A simple calculator built using **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations and supports both mouse and keyboard input.

## ✨ Features

- Basic arithmetic operations (+, −, ×, ÷)
- Percentage and decimal calculations
- Parentheses support
- Fully responsive layout that adapts smoothly to **mobile, tablet, and desktop** screens.
- Keyboard support
  - Numbers and operators
  - Enter (=)
  - Backspace (delete)
  - Esc (clear)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
